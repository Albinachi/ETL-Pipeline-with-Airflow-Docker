# 🚀 Automated A/B Testing Pipeline with Airflow & Docker

Проект демонстрирует полный цикл (End-to-End) продуктовой аналитики: от генерации сырых данных до оценки статистической значимости эксперимента.

## 🛠 Технический стек
*   **Infrastructure:** Docker, Docker Compose
*   **Orchestration:** Apache Airflow 2.7
*   **Database:** PostgreSQL
*   **Language:** Python 3.8 (Pandas, NumPy, SQLAlchemy, SciPy)

## 📊 Архитектура пайплайна
1.  **Data Generation:** Python-скрипт симулирует поведение пользователей (просмотры, клики, покупки) для групп A и B с заданным различием в конверсии.
2.  **ETL (Airflow):**
    *   Создание схемы данных в PostgreSQL.
    *   Загрузка сырых логов.
3.  **Analytics:** Автоматический расчет метрик (Conversion Rate) и проверка гипотезы через T-test (SciPy).
